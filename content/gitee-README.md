## 为什么会有这个项目

普通人打开 GitHub 想找个软件用，会连撞三堵墙：

1. **英文**——README 是英文，安装说明是英文，连报错都是英文；
2. **不知道下哪个**——一个项目十几个 Release 文件，没人告诉小白该点哪个；
3. **坑**——装完才发现要开命令行、装 Python、注册账号，大部分人直接关掉。

所以这里把每个项目都翻译成了大白话，并写清楚**它到底能不能装、装完会踩什么坑**。

## 附：怎么判断一个 GitHub 项目靠不靠谱

高星不等于能用。下面四条能挡掉大部分坑（写内容时用得上）：

1. **看 fork 和 star 的比例**：正常 5%~10%；超过 30%、或 fork 比 star 还多，很可能是刷的。
2. **看最后提交时间**：仓库首页右上角的 last commit，超过一年没动基本当弃坑处理。
3. **看 open issue 和 star 的比例**：几千个 open issue 只配几万 star，说明作者处理不过来。
4. **看有没有能直接装的东西**：Release 里有 `.exe` / `.dmg` / `.apk` 才算考虑过普通用户。
