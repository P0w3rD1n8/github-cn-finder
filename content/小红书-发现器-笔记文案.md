## 正文

```
我在 GitHub 上装过不少东西，踩过的坑大概是这样：
下完发现一年没更新；装完发现没人管；文档全是英文，看半天不知道能干嘛。

所以我做了个「GitHub 中文发现器」小工具，挂在这篇笔记下面：
· 172 个精选项目，每个都有中文说明
· 按用途挑：普通用户 / 学编程 / 自媒体 / 设计师 / 剪辑 / 玩家
· 每个项目四段详情——应用场景、主要功能、适用平台、怎么用起来
· 还标了最近更新和社区活跃度，直接给一句「现在能不能放心用」

用法就三步：
1. 打开小工具，先看榜单（最近涨得快 / 用的人最多）
2. 点一个用途标签，比如「普通用户」，出来 77 个
3. 点进项目，四段看完再决定装不装，能存的点收藏

数据每月更新一次（跟着小工具版本发布），不用再担心"装完才发现一年没动"。
哪里难用、哪里不准，评论区直接说，我改。

更多项目和使用示例我会陆续发在主页，置顶笔记里有一份合集。
```
