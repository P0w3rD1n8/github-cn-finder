## 正文（可直接复制）

```
我没做新项目，就是把 172 个开源项目的「介绍 + 用途」整理成了一个小工具。

起因很直白：想用的时候找不到。收藏夹里一堆链接，英文看不懂，分不清谁在维护、谁早就不更新了。

所以干脆把它们整理成一个能直接用的东西，挂在这篇笔记下面——免费、不用下载，点开就能用👇

里面有什么：
✅ 172 个项目，全部中文介绍，不考英语
✅ 按用途分好了：普通用户 / 学编程 / 自媒体 / 设计 / 剪辑 / 玩家
✅ 每个项目四段详情：能干什么、有什么功能、支持哪些平台、大概怎么装
✅ 标了最近更新和社区活跃度，直接一句"值不值得装"
✅ 中意的点收藏，回头慢慢试

怎么用：
1️⃣ 打开先看榜单（最近涨得快 / 用的人最多）
2️⃣ 点「普通用户」，出来 77 个能直接上手的
3️⃣ 进详情看完四段，再决定装不装

数据每月更新一次，跟着小工具版本走。

更多项目我会陆续发在主页，置顶笔记里有一份合集。
想要哪个项目的详细介绍，评论区说，下篇就写它 🙌
```
