## 这个工具做什么

纯离线，不联网、不收费、不采集任何用户数据。

- **自己判**：5 个问题（更新频率 / star 走势 / 有没有人回 issue / 说明看不看得懂 / 出问题谁修）→ 打分 → 四档结论 + 下一步该做的第一件事
- **看内置 172 个**：内置仓库里那 172 个项目的真实数据（star、24 期星标变化、fork 比、未解决 issue 数、最近推送日），点开直接给四步判断

## 技术合规（对照官方规范逐条）

- `index.html` 在 zip 根目录，其余 3 个文件同级，无多余目录 ✅
- 无内联 `<script>`、无 `onclick=`、无 `eval` / `new Function`、无 `javascript:` ✅
- 经典脚本，无 `type="module"`、无 `import` / `export`；语法为 ES2017，已用 `node --check` 通过 ✅
- 全部相对路径 `./app.css`、`./app.js`、`./tool-data.js`；无任何 `http(s)://` 引用 ✅
- 无网络请求、无定位、无剪贴板、无 Worker、无 iframe、无自建 CSP ✅
- 首屏静态可见（标题 + 两个 Tab + 第一题），不依赖 JS 就绪 ✅
