📖 官方文档摘要

官方定位

一份「从实战项目学编程」的教程清单，汇集教初学者从零动手构建一个完整应用的教程，并按主要编程语言分门别类。

亮点特性
  • 按 C/C++、Python、JavaScript、Go、Rust、Java、Swift、Kotlin 等二十多种语言分类整理
  • 每个教程都要求真刀真枪做出项目：写解释器、操作系统、编译器、数据库、Redis、游戏、TCP/IP 栈等
  • 社区共同维护，并有 link-rot（死链巡检）自动化保障链接可用
快速开始
  1. 在 README 目录里按目标编程语言（如 Python、Go、Rust）找到对应小节
  2. 点击教程链接，跟随教程从零动手构建项目
  3. 想贡献新教程：fork 本仓库，按 CONTRIBUTING.md 提交 Pull Request
