📖 官方文档摘要

官方定位

作者本人为进军大厂软件工程师岗位而整理的一份数月自学备考计划，按这套计划学完后作者入职了 Amazon；它把大学 CS 课程里面试真正用得上的约 75% 内容浓缩成一份路线图。

亮点特性
  • 面向 Amazon、Facebook、Google、Microsoft 等大厂技术面试准备，覆盖软件工程（而非前端/全栈）方向
  • 主题齐全：Big-O 复杂度、数组/链表/栈/队列/哈希表、树、排序、图、递归、动态规划、设计模式、网络、系统设计等
  • 配套每日学习计划、编程题练习清单、选书建议，以及更新简历、找工作、面试流程等求职指南
  • 提供简体中文（translations/README-cn.md）等多语言翻译版本
快速开始
  1. 直接在仓库 README 里从「What is it?」「How to use it」开始通读学习计划，了解所需前置要求（一点编程基础、耐心和时间）
  2. 按「Choose a Programming Language」选定一门语言，配合数据结构与算法书目自学
  3. 按 The Daily Plan 推进各主题，并用 Coding Question Practice 章节刷编程题
  4. 学完后参考「Update Your Resume」「Find a Job」「Interview Process」章节准备面试与求职
