📖 官方文档摘要

官方定位

高性能的自托管照片与视频管理方案，官方 README 自带简体中文版（readme_i18n/README_zh_CN.md）。

亮点特性
  • 手机端 App 打开即自动备份，支持后台备份、按相册选择性备份、防重复
  • 多用户、相册与共享相册、伙伴共享、公开分享、归档与收藏一应俱全
  • 支持 RAW 格式、EXIF/地图元数据查看、LivePhoto/MotionPhoto 备份与回放、360° 全景展示
  • 人脸识别与聚类、按元数据/物体/人脸/CLIP 语义搜索、『几年前的今天』回忆、全局地图
  • 支持 OAuth 登录与 API Key，可自定义存储结构，移动端支持离线浏览
