📖 官方文档摘要

官方定位

由社区成员与 APILayer 共同手工维护的公共 API 大合集，收录各行各业可免费调用的公开 API，是开发者拿来给自己产品直接用的 API 宝库。

亮点特性
  • 收录 2,000+ 免费 API，分 50+ 个分类，与本仓库每日同步并自动测试可用性
  • 每个 API 条目标注鉴权方式、是否支持 HTTPS、是否允许 CORS，便于直接选用
  • 设有『无需密钥』专区，注册都不用，点开就能调用
  • 配套 MCP Servers 目录，让 AI Agent（Claude、Cursor 等）把这些 API 当工具调用
  • 官方检索站 publicapis.lol 支持按分类浏览、按条件筛选、查看 API 实时在线状态
快速开始
  1. 直接浏览仓库 README 里按分类组织的 API 大表，或打开官方检索站 https://publicapis.lol 搜索筛选
  2. 想找免注册即点即用的 API，访问 https://publicapis.lol/no-api-key
  3. 想看今天哪些 API 在线、变慢或宕机，访问 https://publicapis.lol/status
  4. 想贡献新 API：先读 CONTRIBUTING.md，再到 https://github.com/public-apis/public-apis/pulls 提交 PR
