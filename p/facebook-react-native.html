📖 官方文档摘要

官方定位

『Learn once, write anywhere』——用 React 来构建 Android、iOS 等平台的原生应用：JavaScript 写界面，底层用原生代码渲染。

亮点特性
  • Native UI：组件直接渲染成各平台原生 UI，手势、文本缩放、无障碍行为都符合该系统用户的预期
  • React 处处可用：声明式 UI、组件、Hooks、Suspense 在 Android、iOS 及更多平台复用
  • Fast Refresh：改 JavaScript 代码几秒内即可看到效果，无需重新编译原生应用
  • Native Modules 让 JS 同步且类型安全地直接调用平台代码，也可复用社区数千个现成库
  • 由 React Foundation 与众多公司及核心贡献者共同开发维护
快速开始
  1. 官方推荐通过框架起步：npx create-expo-app@latest 创建一个 Expo 项目
  2. 按 Expo 入门指南配置环境：https://docs.expo.dev/get-started/set-up-your-environment/
  3. 新应用也可参考官方 Getting Started 指南：https://reactnative.dev/docs/environment-setup
  4. 若不想用框架，再按 https://reactnative.dev/docs/getting-started-without-a-framework 自行搭建
