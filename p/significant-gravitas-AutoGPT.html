📖 官方文档摘要

官方定位

AutoGPT 是你的一支 AI 专家团队：用大白话交代任务，由 Otto 统筹调度，把内容、销售、研究和重复性事务分派给各专职 AI 专家去完成。

亮点特性
  • 内置 Otto（AI 主管）、Maria（SEO 内容经理）、Max（客户经理）、Frankie（行政助理）等专家角色，可按自己的指令、上下文、技能和已连接应用定制
  • 可视化工作流编排器：连线积木、加分支逻辑、控制执行步骤，可从市场模板复用或自建
  • 提供 API 与 MCP server，可从自己的代码或 AI 编码 agent 直接调用工作流
  • 既有托管付费平台，也支持单容器 Docker 自托管、自带模型凭据并自行管理运行
快速开始
  1. 自托管最快方式，用 Docker Hub 单容器镜像启动：docker run -d --name autogpt --restart unless-stopped --shm-size 2g --ulimit nofile=65536:65536 -p 127.0.0.1:3000:3000 -e AUTOGPT_PUBLIC_URL=http://localhost:3000 -v autogpt-data:/data significantgravitas/autogpt:latest
  2. 首次启动等待几分钟后打开 http://localhost:3000 注册账号
  3. 把自己提升为管理员：docker exec autogpt autogpt-admin promote you@example.com
  4. 或直接注册托管平台试用：https://platform.agpt.co/signup ；自托管细节见 https://agpt.co/docs/platform/self-hosting/single-container
