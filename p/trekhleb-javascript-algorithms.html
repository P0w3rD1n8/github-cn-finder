📖 官方文档摘要

官方定位

用 JavaScript 实现的经典算法与数据结构示例合集，每个算法/数据结构都配有独立 README 讲解与延伸阅读（含 YouTube 视频），并提供简体中文等多语言版本。

亮点特性
  • 覆盖链表、双链表、队列、栈、哈希表、堆、优先队列、Trie、二叉搜索树、AVL/红黑树、线段树、图、并查集、布隆过滤器、LRU 缓存等数据结构
  • 算法按数学、集合、字符串、排序、搜索、递归、动态规划等主题分类，并以 B（初级）/A（高级）标注难度
  • 附带 Big O 增长曲线、数据结构操作复杂度表与各排序算法复杂度对照表
快速开始
  1. clone 仓库后在 ./src/playground/playground.js 中动手试验数据结构与算法
  2. 为自己的代码编写测试于 ./src/playground/__test__/playground.test.js
  3. 运行 npm test -- 'playground' 验证 playground 代码是否按预期工作
