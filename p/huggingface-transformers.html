📖 官方文档摘要

官方定位

Hugging Face Transformers 是用于推理和训练的 SOTA 预训练模型框架，统一了文本、计算机视觉、音频、视频及多模态模型的定义，是整个 ML 生态里训练框架、推理引擎和周边库共同对接的模型定义枢纽。官方提供简体中文 README（i18n/README_zh-hans.md）。

亮点特性
  • 统一 API 使用所有预训练模型，面向用户只需学三个类，上手门槛低
  • 覆盖 NLP、计算机视觉、音频、视频、多模态上千种模型架构，Hub 上有百万级模型 checkpoint 可直接用
  • 同一份模型可在 PyTorch/JAX/TF2 之间自由迁移，3 行代码即可训练 SOTA 模型
  • 与 Axolotl、Unsloth、DeepSpeed、vLLM、SGLang、TGI、llama.cpp、mlx 等主流训练/推理生态兼容
快速开始
  1. 要求 Python 3.11+ 与 PyTorch 2.6+，先建虚拟环境：python -m venv .my-env 再激活
  2. 安装：pip install "transformers[torch]"（或 uv pip install "transformers[torch]"）
  3. 用高层 Pipeline 一行跑推理：from transformers import pipeline → pipeline(task="text-generation", model="Qwen/Qwen2.5-1.5B")
  4. 命令行直接和模型聊天（需先 transformers serve）：transformers chat Qwen/Qwen2.5-0.5B-Instruct
  5. 从源码安装最新版：git clone https://github.com/huggingface/transformers.git 后 pip install '.[torch]'
