📖 官方文档摘要

官方定位

开源、跨平台的 JavaScript 运行时环境，由 OpenJS 基金会支持，项目采用开放治理模式（设技术指导委员会 TSC）。

亮点特性
  • 按语义化版本发布，每年 4 月推出新主版本；LTS 长期支持线提供 30 个月稳定与安全维护
  • 区分 Alpha / Current / LTS / Nightly 多种发布类型，分别面向库作者、CI 与生产环境
  • 官方提供各平台预编译二进制、安装包与源码 tarball，并附带可 GPG 校验的 SHASUMS256.txt.asc
快速开始
  1. 前往官网下载页获取二进制与安装包：https://nodejs.org/en/download/
  2. 查看最新 Current 版 API 文档：https://nodejs.org/api/（历史版本文档在各 release 目录的 docs 子目录）
  3. 校验下载包：用官方 release-keys 公钥导入后执行 curl -fsO "https://nodejs.org/dist/${VERSION}/SHASUMS256.txt.asc" 并用 gpgv + shasum --check 校验
  4. 从源码构建见 BUILDING.md
求助渠道
