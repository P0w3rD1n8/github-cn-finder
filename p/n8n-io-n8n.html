📖 官方文档摘要

官方定位

n8n 是面向 AI agent 与工作流自动化的 fair-code 平台：把可视化画布和自定义代码结合，可自托管或用云端版，连接 1500+ 集成，从原型一路用到生产。

亮点特性
  • AI 原生自动化：用你自己的数据、模型和工具构建并落地多步 AI 工作流与 agent
  • 模型不锁定：可接 OpenAI、Anthropic、Google 或开源模型，换厂商不用改架构
  • 可视化搭建 + JavaScript/Python/npm 代码混用，支持逻辑分支、人工审批与全链路可观测
  • 1500+ 集成与 9000+ 工作流模板，企业级自带 RBAC、审计日志，适合处理敏感数据
快速开始
  1. 一键脚本安装（需已装 Docker）：curl -fsSL https://get.n8n.io | sh
  2. 或手动用 Docker：docker volume create n8n_data 再执行 docker run -it --rm --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n
  3. 浏览器打开 http://localhost:5678 进入编辑器开始编排工作流
  4. 也可直接使用云端版 https://app.n8n.cloud/login
