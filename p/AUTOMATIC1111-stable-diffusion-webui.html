📖 官方文档摘要

官方定位

用 Gradio 库实现的 Stable Diffusion 网页图形界面。

亮点特性
  • 原版 txt2img / img2img 模式，支持 Outpainting、Inpainting、Prompt Matrix、循环采样、X/Y/Z 参数对比图
  • 注意力权重控制、负面提示词、不限 token 长度的提示词、CLIP interrogator 反推提示词
  • 集成 GFPGAN/CodeFormer 人脸修复、RealESRGAN/ESRGAN/SwinIR 等放大模型，支持 Textual Inversion、Hypernetwork、LoRA
  • 一键安装脚本、支持低至 4GB 显存显卡（2GB 也有报告可用）、提供 API 接口与丰富的社区扩展生态
快速开始
  1. Windows + NVIDIA 显卡自动安装：先装 Python 3.10.6（安装时勾选 Add Python to PATH）和 git
  2. 克隆仓库：git clone https://github.com/AUTOMATIC1111/stable-diffusion-webui.git
  3. 以普通用户身份双击运行 webui-user.bat
  4. Linux 用户先装依赖，再 wget -q https://raw.githubusercontent.com/AUTOMATIC1111/stable-diffusion-webui/master/webui.sh 并执行 webui.sh
