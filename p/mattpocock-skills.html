📖 官方文档摘要

官方定位

作者 Matt Pocock 日常用于『真工程』（而非 vibe coding）的 AI 编码代理技能（agent skills）合集，设计小巧、易改造、可组合，适配任意模型。

亮点特性
  • 工程类技能：grill-with-docs（需求拷问并生成领域术语表 GLOSSARY.md/ADR）、tdd（红绿重构循环）、diagnosing-bugs、code-review、improve-codebase-architecture 等
  • 通用效率类技能：grill-me、handoff（会话交接文档）、teach、wait-what 等
  • 覆盖 Claude Code、Codex、GitHub Copilot、Gemini CLI 及其他代理的多平台安装方式
快速开始
  1. Claude Code 安装：claude plugin install mattpocock-skills@claude-plugins-official（自动更新）
  2. 其他代理通用安装：npx skills@latest add mattpocock/skills -a <agent>（如 cursor、opencode 等）
  3. 在每个仓库中运行一次 /setup-matt-pocock-skills，配置 issue 跟踪器、分诊标签与文档保存目录
  4. 之后按需使用 /grill-me、/tdd、/implement、/code-review 等技能
