📖 官方文档摘要

官方定位

把 Android 设备画面（视频+音频）通过 USB 或 TCP/IP 投屏到电脑、并用电脑键鼠控制的免费开源工具，不需要 root、不需要在手机上装 App，支持 Linux、Windows、macOS。

亮点特性
  • 轻量原生、低延迟（35~70ms）、约 1 秒启动首帧，支持 30~120fps、1920×1080 以上画质
  • 支持音频转发（Android 11+）、屏幕录制、虚拟显示屏、息屏投屏、双向复制粘贴、摄像头投屏与 V4L2 网络摄像头（仅 Linux）
  • HID 物理键鼠模拟、游戏手柄支持、OTG 模式（无需 USB 调试即可控制设备）
  • 无账号、无广告、无需联网；Android 5.0（API 21）起支持
快速开始
  1. 在 Android 设备上开启 USB 调试（小米等机型还需额外开启 USB 调试（安全设置）并重启）
  2. 按平台下载安装：Linux / Windows / macOS 分别见项目 doc 文档页
  3. 连接设备后直接运行 scrcpy 开始投屏
  4. 常用示例：scrcpy --video-codec=h265 -m1920 --max-fps=60 限分辨率帧率；scrcpy --otg OTG 纯控制模式；scrcpy --gamepad=uhid 用手柄控制
