📖 官方文档摘要

官方定位

功能丰富的命令行音视频下载器，支持数千个网站下载，是 youtube-dl 的衍生项目（基于已停止维护的 youtube-dlc）。

亮点特性
  • 支持数千个网站的音视频下载，站点列表见 supportedsites.md
  • 提供 stable / nightly / master 三种发布渠道，可用 --update-to 随时切换版本或回退到指定 tag
  • 内置 SponsorBlock 广告片段跳过、强大的格式选择（-f/--format）与丰富的后处理选项
  • 支持插件扩展、配置文件、netrc 认证与高度自定义的输出模板
快速开始
  1. 从 Releases 下载对应平台的独立可执行文件：Windows 用 yt-dlp.exe、macOS 用 yt-dlp_macos、Linux/BSD 用 yt-dlp
  2. 或用 pip 安装：python -m pip install -U "yt-dlp[default]"；装 nightly 预发布：python -m pip install -U --pre "yt-dlp[default]"
  3. 基本用法：yt-dlp [OPTIONS] [--] URL [URL...]
  4. 更新：release 二进制运行 yt-dlp -U；pip 安装则重新执行安装命令；遇到 stable 版问题先 yt-dlp --update-to nightly 再报 bug
  5. 详细安装与依赖说明见官方 Wiki：https://github.com/yt-dlp/yt-dlp/wiki/Installation
