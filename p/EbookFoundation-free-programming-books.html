📖 官方文档摘要

官方定位

一份多语言免费编程学习资源清单，最初克隆自 StackOverflow 的『免费编程书单』帖子，现由非营利组织 Free Ebook Foundation 托管维护，以协作方式持续更新。

亮点特性
  • 免费编程书籍按编程语言和按主题两大主线分门别类整理
  • 覆盖几十种语言版本，其中包含中文书单 books/free-programming-books-zh.md
  • 除书籍外还延伸出免费课程、播客等配套资源清单
  • 配套动态搜索站，可按书名或作者实时检索
  • 内容以 CC BY 4.0 许可开放，欢迎社区按贡献指南增补
快速开始
  1. 在仓库 README 里按语言或主题点开对应清单文件（如中文见 books/free-programming-books-zh.md）
  2. 想按书名或作者搜索：打开 https://ebookfoundation.github.io/free-programming-books-search/
  3. 想要更好读的网页版浏览：访问 https://ebookfoundation.github.io/free-programming-books/
  4. 想贡献资源：先读 docs/CONTRIBUTING.md（新手先看 docs/HOWTO.md），并遵守行为准则
求助渠道

非营利组织主页 https://ebookfoundation.org ；问题反馈走 GitHub Issues https://github.com/EbookFoundation/free-programming-books/issues
