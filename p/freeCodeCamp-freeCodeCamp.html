📖 官方文档摘要

官方定位

freeCodeCamp.org 的开源代码库与课程体系——一个友好的免费学编程社区，由捐赠支持的 501(c)(3) 慈善机构运营，帮助忙碌的成年人转行进入技术行业。

亮点特性
  • 全栈 Web 开发与机器学习课程完全免费、自定进度，包含数千个交互式编程挑战
  • 提供多项免费开发者认证：响应式网页设计、JavaScript、前端库、Python、关系数据库、后端与 API 等
  • 另设面向开发者的免费语言认证（英语 A2/B1、西班牙语、中文 A1），按国际水平分级
  • 每门认证需完成 5 个必修项目并通过考试，证书永久有效可挂 LinkedIn
  • 社区配套论坛、YouTube 免费课程频道、数千篇技术文章，帮助面试与实战
快速开始
  1. 直接访问 https://www.freecodecamp.org 注册账号开始学习
  2. 在 https://www.freecodecamp.org/learn 选择目标认证课程（如 Responsive Web Design、JavaScript）
  3. 按模块完成互动课程、练习与测验，做完 5 个必修项目后参加考试拿证
  4. 想为本项目贡献代码：阅读 https://contribute.freecodecamp.org 按指引提交 PR
求助渠道

官方论坛 https://forum.freecodecamp.org （通常数小时内有人解答）；Discord https://discord.gg/Z7Fm39aNtZ ；YouTube https://youtube.com/freecodecamp ；技术文章 https://www.freecodecamp.org/news
