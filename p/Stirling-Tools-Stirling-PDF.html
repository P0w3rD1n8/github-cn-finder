📖 官方文档摘要

官方定位

Stirling PDF 是一个强大的开源 PDF 处理平台：可当个人桌面应用、浏览器网页应用运行，也可自托管成带私有 API 的服务器，全程不用把文件交给外部服务。

亮点特性
  • 50+ PDF 工具：编辑、合并、拆分、签名、脱敏、转换、OCR、压缩等一应俱全
  • 可视化无代码自动化流水线，几乎所有工具都开放 REST API，可批量处理海量 PDF
  • 企业级能力：SSO 单点登录、操作审计、灵活的本地部署；界面支持 40+ 种语言
  • 三种使用形态：桌面客户端、浏览器 UI、自托管服务器+私有 API
快速开始
  1. Docker 一键启动：docker run -p 8080:8080 docker.stirlingpdf.com/stirlingtools/stirling-pdf
  2. 浏览器打开 http://localhost:8080 即可使用
  3. 桌面版、Kubernetes 等完整安装选项见文档指南 https://docs.stirlingpdf.com/#documentation-guide
