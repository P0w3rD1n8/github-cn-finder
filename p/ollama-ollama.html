📖 官方文档摘要

官方定位

Ollama 让你用开源模型快速起步，在本地或云端以完全隐私的方式运行和管理最新发布的开源大模型。

亮点特性
  • 一行命令即可在本地拉取并运行开源大模型（如 Gemma 等），模型库见 ollama.com/library
  • 内置 REST API，并有官方 Python（ollama-python）和 JS（ollama-js）SDK，方便接入自己的应用
  • 可一键集成 Claude Code、Codex、Copilot CLI、OpenCode 等编程 agent，也能接 WhatsApp/Telegram/Slack/Discord 做个人 AI 助手
  • 推理后端基于 Georgi Gerganov 发起的 llama.cpp 项目
快速开始
  1. macOS/Linux 安装：curl -fsSL https://ollama.com/install.sh | sh；Windows 安装：irm https://ollama.com/install.ps1 | iex
  2. 运行 ollama 启动，或直接 ollama run gemma4 与模型对话
  3. 启动编程集成：ollama launch claude（也支持 openclaw 等助手）
  4. 用 REST API 调用：curl http://localhost:11434/api/chat -d '{"model":"gemma4","messages":[{"role":"user","content":"Why is the sky blue?"}],"stream":false}'
  5. Python 接入：pip install ollama；JS 接入：npm i ollama
