📖 官方文档摘要

官方定位

一个单文件 CLAUDE.md 项目，把 Andrej Karpathy 对 LLM 编程缺陷的观察提炼成四条行为准则，用于改善 Claude Code 的输出表现。

亮点特性
  • 准则一 先思考再编码：明确陈述假设、给出多种解读、该反驳就反驳、困惑时停下来提问
  • 准则二 简洁优先：只写解决问题所需的最少代码，不做投机性抽象、不写没要求的配置项和不可能场景的错误处理
  • 准则三 外科手术式改动：只动该动的代码，不顺手改进相邻代码/注释/格式，只清理自己改动产生的死代码
  • 准则四 目标驱动执行：把命令式任务改写成带验证标准的目标（先写复现测试再修 bug），让 LLM 自主循环到通过
  • 仓库自带 Cursor 规则文件，同一套准则在 Cursor 中同样生效
快速开始
  1. 推荐方式（Claude Code 插件）：在 Claude Code 内先执行 /plugin marketplace add forrestchang/andrej-karpathy-skills
  2. 再执行 /plugin install andrej-karpathy-skills@karpathy-skills，准则即作为插件跨所有项目生效
  3. 单项目使用：新项目执行 curl -o CLAUDE.md https://raw.githubusercontent.com/forrestchang/andrej-karpathy-skills/main/CLAUDE.md
  4. 已有项目追加：echo "" >> CLAUDE.md 后 curl https://raw.githubusercontent.com/forrestchang/andrej-karpathy-skills/main/CLAUDE.md >> CLAUDE.md
