📖 官方文档摘要

官方定位

又一个用 Rust 写的远程桌面方案，开箱即用、无需任何配置，数据完全由自己掌控；可以直接用官方中继服务器，也可以自建服务器，甚至自己写一个 rendezvous/relay 服务。

亮点特性
  • 开箱即用零配置，装上就能远程控制，强调用户对数据的完全掌控
  • 服务端完全开放：可使用官方/自建中继服务器，也可参考 rustdesk-server-demo 自己写
  • 支持文件传输、TCP 隧道等远程办公常用能力
  • 桌面端 GUI 采用 Flutter（旧版 Sciter），覆盖 Windows / Linux / macOS 与移动端
  • 官方发布正式版与 nightly 每日构建，并提供 F-Droid、Flathub 安装渠道
快速开始
  1. 普通用户直接从 Release 页下载安装包：https://github.com/rustdesk/rustdesk/releases （安卓也可装 F-Droid 版本）
  2. 开发者先准备好 Rust + C++ 构建环境，安装 vcpkg 并设置 VCPKG_ROOT，再执行 vcpkg install libvpx libyuv opus aom
  3. 克隆仓库后编译运行：git clone --recurse-submodules https://github.com/rustdesk/rustdesk 然后 cargo run
  4. Docker 构建方式：git clone https://github.com/rustdesk/rustdesk && cd rustdesk && git submodule update --init --recursive && docker build -t "rustdesk-builder" .
  5. 之后每次构建执行：docker run --rm -it -v $PWD:/home/user/rustdesk -v rustdesk-git-cache:/home/user/.cargo/git -v rustdesk-registry:/home/user/.cargo/registry -e PUID="$(id -u)" -e PGID="$(id -g)" rustdesk-builder
