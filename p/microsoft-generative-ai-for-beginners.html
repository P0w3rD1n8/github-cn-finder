📖 官方文档摘要

官方定位

微软 Cloud Advocates 出品的 21 课开源课程（Generative AI for Beginners 第 3 版），教你从零开始构建生成式 AI 应用。

亮点特性
  • 21 节课分 Learn 概念课与 Build 实战课，每课配书面讲义、短视频、Python 和 TypeScript 代码示例
  • 内容覆盖 LLM 基础、提示工程、文本生成/聊天/搜索/图像应用、函数调用、RAG 与向量数据库、AI Agent、模型微调、SLM、Mistral 与 Meta 模型等
  • 支持 Azure OpenAI、Microsoft Foundry Models、OpenAI API、Foundry Local 本地离线模型多种运行方式
  • 50+ 语言翻译（含简体中文 translations/zh-CN），并提供稀疏检出克隆方式跳过翻译目录加速下载
快速开始
  1. （可选）稀疏检出克隆以跳过翻译目录：git clone --filter=blob:none --sparse https://github.com/microsoft/generative-ai-for-beginners.git，然后 cd generative-ai-for-beginners 并 git sparse-checkout set --no-cone '/*' '!translations' '!translated_images'
  2. 先读 ./00-course-setup/README.md 完成开发环境搭建
  3. 按 21 课顺序学习，每课可配合 Python 或 TypeScript 代码动手实践
