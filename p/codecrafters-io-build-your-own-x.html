官方定位

一份精心整理的『从零动手造技术』分步教程合集，收录手把手重建数据库、Git、Docker、编程语言、Web 服务器等热门技术的优质指南，核心理念引自费曼：『我不能创造的，我就不能理解』。

  • 每篇教程标注所用语言（Python / Go / C++ / Rust / Java / TypeScript 等）与形式（图文 / 视频）
  • 持续更新的社区合集，可在 Issues 中建议新增或改进教程
快速开始
  1. 直接在仓库 README 目录中按主题跳转（如 Build your own Database / Git / Docker）
  2. 点击某篇教程链接前往外部原文网站，按其步骤从零实现对应技术
