📖 官方文档摘要

官方定位

自托管 AI 平台，官方口号 a home for AI——可扩展、功能丰富、易用，能完全离线运行，对接 Ollama 与 OpenAI 兼容 API，提供与厂商无关的本地 + 云端模型统一界面。

亮点特性
  • 部署简单：支持 pip、Docker、Kubernetes（kubectl/kustomize/helm），提供 :ollama、:cuda 标签镜像
  • 广泛模型接入：任意 OpenAI 兼容 API 加本地 Ollama，可对接 LMStudio、GroqCloud、OpenRouter、vLLM 等
  • 本地 RAG：支持 9 种向量数据库、BM25+向量混合搜索与重排，多种文档解析引擎，用 # 命令加载文档或网页
  • 细粒度 RBAC 角色与分组权限，插件系统（Filters/Actions/Pipes/Tools/Skills）与 MCP/OpenAPI 工具接入
  • 内置 AI 笔记、频道协作、持久记忆、语音视频通话、多模型对话、企业级 LDAP/SSO/SCIM 等能力
快速开始
  1. pip 安装（需 Python 3.12）：pip install open-webui，然后 open-webui serve，访问 http://localhost:8080
  2. Docker 运行（本机有 Ollama 时）：docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data --name open-webui --restart always ghcr.io/open-webui/open-webui:main
  3. 若 Ollama 在另一台服务器，加 -e OLLAMA_BASE_URL=https://example.com 指定地址
  4. 仅用 OpenAI API 时加 -e OPENAI_API_KEY=your_secret_key；启动后访问 http://localhost:3000
