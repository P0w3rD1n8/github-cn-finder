📖 官方文档摘要

官方定位

用于构建用户界面的 JavaScript 库。

亮点特性
  • 声明式：为每个状态设计简单视图，数据变化时 React 高效更新并渲染正确的组件
  • 组件化：构建封装了自身状态的组件再组合成复杂 UI，组件逻辑用 JavaScript 编写而非模板
  • 学一次，到处用：不绑定技术栈，可用 Node 在服务端渲染，用 React Native 开发移动应用
  • 从一开始就为渐进式采用设计，可在既有项目中按需引入任意多/少的 React
快速开始
  1. 新手先按官方 Quick Start 上手：https://react.dev/learn
  2. 在已有项目中引入 React：https://react.dev/learn/add-react-to-an-existing-project
  3. 新建项目：https://react.dev/learn/start-a-new-react-project
  4. 第一个示例：用 import { createRoot } from 'react-dom/client' 创建根节点并 root.render(<HelloMessage name="Taylor" />)
