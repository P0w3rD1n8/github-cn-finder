📖 官方文档摘要

官方定位

Bootstrap 是一套简洁、直观、强大的前端框架，让更快、更轻松地做 Web 开发；仓库默认分支当前用于 Bootstrap 6 的开发（Bootstrap 5 见 v5-dev 分支）。

亮点特性
  • 提供编译与压缩版 CSS/JS，内含网格、重置（reboot）、工具类等完整前端资产
  • 借助 CSS 逻辑属性原生支持 LTR/RTL 双向布局，只需在 HTML 上设置 dir="rtl"
  • 打包版 JS 内置 Floating UI 与 Vanilla Calendar Pro
  • 同时支持 npm、yarn、bun、Composer、NuGet 等多种安装渠道
快速开始
  1. 任选一种方式安装：npm install bootstrap@6.0.0-alpha.1（或 git clone https://github.com/twbs/bootstrap.git、下载 release 压缩包）
  2. 阅读官方入门页了解框架内容、模板与示例：https://getbootstrap.com/docs/6.0/getting-started/
  3. 本地运行文档站：先 npm install，再 npm run test，然后在仓库根目录 npm run docs-serve
  4. 浏览器打开 http://localhost:9001 即可本地预览文档
