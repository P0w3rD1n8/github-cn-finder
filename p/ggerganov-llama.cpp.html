📖 官方文档摘要

官方定位

用纯 C/C++ 实现的大语言模型（及视觉语言模型）推理引擎，目标是以最少的配置、在本地和云端各种硬件上都实现 SOTA 级别的推理性能。

亮点特性
  • 纯 C/C++ 实现、零依赖，构建在 ggml 库之上
  • Apple Silicon 一级优化（ARM NEON、Accelerate、Metal）；x86 支持 AVX/AVX2/AVX512/AMX；RISC-V 也有支持
  • 支持 1.5/2/3/4/5/6/8 bit 整数量化，推理更快、内存更省
  • CUDA 自研 kernel，另支持 HIP（AMD）、MUSA（摩尔线程）、Vulkan、SYCL、Metal 等后端，并支持 CPU+GPU 混合推理跑下超过显存容量的模型
快速开始
  1. 安装（Linux/macOS）：curl -LsSf https://llama.app/install.sh | sh；Windows PowerShell：irm https://llama.app/install.ps1 | iex
  2. 其他途径：访问 https://llama.app 按指引操作，或从 releases 页下载预编译二进制，或按 docs/build.md 从源码编译
  3. 装好后直接从 Hugging Face 拉模型跑 CLI：llama cli -hf ggml-org/Qwen3.5-0.8B-GGUF
  4. 启动 OpenAI 兼容 API 服务：llama serve -hf ggml-org/Qwen3.5-0.8B-GGUF
