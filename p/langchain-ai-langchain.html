📖 官方文档摘要

官方定位

智能体（Agent）工程平台，用于构建智能体与 LLM 驱动应用的框架，把可互操作组件与第三方集成串联起来，在底层技术快速演进时简化 AI 应用开发。

亮点特性
  • 通过模型、嵌入、向量库等统一抽象接口连接各类组件，模型可随时替换试验
  • 实时数据增强：轻松把 LLM 接入多类数据源与内外部系统，集成生态丰富
  • 生态完整：Deep Agents（高层智能体）、LangGraph（可控智能体工作流编排）、LangSmith（评估、可观测性、调试与部署）
快速开始
  1. 安装：uv add langchain
  2. 最小示例：from langchain.chat_models import init_chat_model，再 model = init_chat_model("openai:gpt-5.5") 与 result = model.invoke("Hello, world!")
  3. 完整文档：https://docs.langchain.com/oss/python/langchain/overview
  4. 需要高级智能体编排时改用 LangGraph；JS/TS 等价库见 LangChain.js
