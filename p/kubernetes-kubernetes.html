📖 官方文档摘要

官方定位

开源系统，用于跨多台主机管理容器化应用，提供应用部署、维护与扩缩容的基本机制；源自 Google Borg 的大规模生产经验，由云原生计算基金会 CNCF 托管。

亮点特性
  • 跨主机统一管理容器化应用，覆盖部署、维护与水平扩缩容全流程
  • 由 CNCF 托管，治理、社区会议与用户案例机制成熟
  • 提供官方文档与免费入门课程，并列出可作为库引用的发布组件清单
快速开始
  1. 日常使用先读官方文档：https://kubernetes.io
  2. 免费课程：Udacity《Scalable Microservices with Kubernetes》
  3. 有 Go 环境从源码构建：git clone https://github.com/kubernetes/kubernetes → cd kubernetes → make
  4. 有 Docker 环境则改用 make quick-release；完整开发说明见 git.k8s.io/community
