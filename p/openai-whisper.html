📖 官方文档摘要

官方定位

OpenAI 开源的通用语音识别模型，在大规模多样化音频数据集上训练，是一个多任务模型，能同时做多种语言的语音识别、语音翻译和语种识别。

亮点特性
  • 基于 Transformer 序列到序列架构，用一个模型替代传统语音处理流水线的多个环节
  • 提供 tiny / base / small / medium / large / turbo 六种尺寸，turbo 是 large-v3 的加速优化版，按显存和速度取舍
  • 多语言模型可把非英语语音直接翻译成英文
  • 同时提供命令行工具与 Python API，接入 Colab 示例可直接上手
  • 代码与模型权重均以 MIT 许可发布
快速开始
  1. 安装最新版：pip install -U openai-whisper（或 pip install git+https://github.com/openai/whisper.git 装最新提交）
  2. 安装命令行依赖 ffmpeg，如 sudo apt install ffmpeg、brew install ffmpeg 或 choco install ffmpeg
  3. 命令行转录音频：whisper audio.flac audio.mp3 audio.wav --model turbo
  4. 指定语种转录：whisper japanese.wav --language Japanese
  5. 把语音翻译成英文：whisper japanese.wav --model medium --language Japanese --task translate
  6. Python 调用：import whisper; model = whisper.load_model("turbo"); result = model.transcribe("audio.mp3"); print(result["text"])
