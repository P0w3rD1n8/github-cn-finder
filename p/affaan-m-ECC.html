📖 官方文档摘要

官方定位

给 AI 编程助手（Agent）装上一套协调一致的工程系统与工具箱：先规划再写码、用测试验证改动、从全新上下文审查自己的工作、记住要点，并把重复的成功经验沉淀为可复用的技能和工作流。MIT 开源，今天在 Claude Code 上体验最好，同时提供 Codex、Qoder 原生插件路径，以及 Cursor、OpenCode、Gemini、Zed、GitHub Copilot 等工具的能力适配。

亮点特性
  • 内置 71 个专职 Agent（规划、审查、构建修复、安全、架构、领域工作）和 311 个技能（TDD、调研、安全、文档、前端、数据、ML、运维等）
  • 97 个命令入口，加上 Hooks、规则、持久记忆与持续学习，把 plan→test→implement→review→verify→remember→improve 固化成 Agent 的默认工作方式
  • 内置 AgentShield 安全扫描，检查 prompts、hooks、MCP 配置、权限、密钥与 agent 文件
  • 一次安装即可跨多种主流 AI 编程工具使用，无需在每个 prompt 里重复搭建流程
快速开始
  1. 准备依赖：安装 Node.js 18+、Git 和 Claude Code 2.1+，在 PowerShell 中用 node --version、git --version、claude --version 确认可用
  2. 运行引导式安装：npx ecc-universal@2.2.3 setup
  3. 个人典型配置选 Global user、Standard hooks 并确认
  4. 新开一个 Claude Code 会话，运行 /plugin list 确认 ecc@ecc 已启用
