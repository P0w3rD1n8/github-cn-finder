📖 官方文档摘要

官方定位

『Code - OSS』开源仓库，微软与社区共同开发 Visual Studio Code 的源代码，在 MIT 许可下对所有人开放；VS Code 产品是基于该仓库、带微软定制的发行版。

亮点特性
  • 兼顾代码编辑器的简洁与编辑-构建-调试核心循环：全面的代码编辑、导航与理解支持，轻量调试与丰富的扩展模型
  • 每月更新新功能与缺陷修复，提供 Windows/macOS/Linux 稳定版与每日更新的 Insiders 版
  • 内置多语言语法与 snippets 扩展，并支持 Dev Containers / GitHub Codespaces 开发容器
快速开始
  1. 普通用户直接在官网下载安装：https://code.visualstudio.com/Download
  2. 想每天体验最新版本：安装 Insiders 版 https://code.visualstudio.com/insiders
  3. 从源码构建与参与开发：参考 Wiki 的 How to Contribute（https://github.com/microsoft/vscode/wiki/How-to-Contribute）
  4. 可用命令 Dev Containers: Clone Repository in Container Volume... 一键把源码克隆进开发容器（建议 4 核 / 6GB 内存以上）
