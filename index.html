GitHub 中文发现器v1.18 是一个纯前端的单页小应用，帮中文用户发现 GitHub 上的优质开源项目。
· 内置 152 个精选项目，每条都有大白话中文简介，专为英文小白翻译
· 星标等数据由 GitHub Actions 每小时自动抓取真实值，不靠手填数字
· 搜索时会同时查询 GitHub 官方接口，网络不通时自动只展示本地精选
· 收藏保存在你的浏览器本地，不上传任何数据
· 📮 联系/合作：11589839@qq.com（点一下复制）
· 🌐 项目主页：GitHub 仓库（点⭐支持 / 反馈问题）

项目还在成长中，我知道它还不够好：精选项目数量有限、部分中文介绍可能不够准确、功能也在不断完善中。
如果你有好项目推荐、翻译修正或功能建议，欢迎随时告诉我 📮，每一条建议我都会认真看。
后续计划：持续扩充精选库 · 一键生成项目海报 · 实时新星推荐 · 更多人群分类。
免责声明：本站为个人兴趣项目，内容仅供学习参考，不构成任何形式的推荐或担保。项目中文介绍为人工整理，可能存在偏差；星标等数据由程序自动抓取，以 GitHub 官方信息为准。使用任何项目前，请以该项目官方文档为准，自行评估风险（尤其涉及安装运行、自托管或隐私数据的项目）。页内国内镜像链接指向 GitCode / Gitee 等第三方平台，由对应平台同步维护，并非本站自建，请以镜像平台实际内容为准。
