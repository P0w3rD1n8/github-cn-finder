# GitHub 中文发现器 🧭

> 不懂英文，也能轻松逛 GitHub
> 当前版本：**v1.24.0**（2026-10-30）

一个面向中文用户的 GitHub 优质开源项目发现工具，把 GitHub 上最值得关注的项目翻译成大白话，让完全不懂英文、不懂编程的小白也能轻松找到好东西。

## ✨ 核心功能

- **百个精选优质项目（持续收录中）**：AI、实用工具、学编程、游戏娱乐、网页、后台、手机 App 等九大分类，全部配中文大白话介绍，点开还有**四段式小白详情**（应用场景 / 主要功能 / 适用平台 / 怎么用起来）
- **每日推荐**：每天自动为你挑选一个值得一看的好项目
- **实时热门榜单**：今日 / 本周 / 本月 / 今年 / 全站 Top 20，实时抓取 GitHub 数据；今日榜为**星标增速榜**（较上次快照的 star 增量，数据截至时间一目了然）
- **中文搜索**：输入中文关键词（如"漫画""AI""教程"），本地精选 + GitHub 实时搜索双重命中，知名项目自动显示中文简介
- **收藏**：收藏到"我的"列表，数据自动保存在本地
- **一键分享**：生成分享文案，转发到微信、朋友圈、小红书
- **人群分类**：按"程序员 / 学编程 / 自媒体创作者 / 普通用户 / 游戏玩家"筛选，找到适合自己的那一类
- **作者信息**：每个项目标注作者（个人/组织），点击可查看作者简介和代表作（可点击跳转）
- **国内镜像直达**：多数精选项目提供国内镜像入口，附来源说明（平台官方同步，非作者自建）

## 📱 怎么使用

1. 用手机浏览器打开项目链接
2. 点浏览器菜单 → **"添加到主屏幕"**，就会像 App 一样出现在手机桌面上
3. 或者直接在电脑浏览器打开网页使用

## 🛠 技术说明

- 纯前端实现：`index.html`（样式 + 逻辑）+ `data.js`（项目数据），无需服务器、无需安装
- 数据来源：GitHub 官方 API（搜索 / 榜单实时数据）
- 精选项目库内置在 `data.js` 中，中文介绍逐条大白话翻译，专为英文小白准备；`validate-data.js` 在 CI 校验完整性、去重与仓库存在性
- 数据管线：GitHub Actions 每小时自动抓取 **152 个**精选库的真实 star / fork / issue / 语言，写入 repos.json；带成功率门槛与快照 diff（增速榜数据源）
- PWA 支持：可安装到手机主屏幕；静态资源走 stale-while-revalidate（秒开 + 后台更新，断网也能打开上次内容），`repos.json` 走 network-first 保证星标不慢一版
- 收藏数据存储：浏览器本地存储（localStorage）

## 📂 项目结构

| 文件 | 说明 |
|---|---|
| index.html | 主程序（样式 + 全部交互逻辑） |
| data.js | 精选库数据（项目、中文简介、详情、人群标签、镜像表） |
| validate-data.js | 数据校验脚本（CI 每次 push 跑） |
| fetch-data.py | 数据采集脚本（每小时抓真实 star/fork/issue/语言） |
| build_pages.py | 静态页生成脚本（改 data.js 后自动生成 p/ 项目页 + list.html + sitemap.xml） |
| p/ | 152 个精选项目的独立静态页（SEO / 分享落地页，由 build_pages.py 生成） |
| list.html | 全部精选项目清单页（build_pages.py 生成） |
| repos.json | 采集结果（前端启动时加载，覆盖内置兜底数据） |
| .github/workflows/ | data-update.yml 定时采集；build-pages.yml 静态页生成；validate.yml 数据校验 |
| manifest.json | PWA 配置（手机安装为 App） |
| sw.js | 离线缓存服务（静态资源 SWR，数据文件 network-first） |
| og-cover.png | 分享封面（1200×630，微信/X 外链预览） |
| icon.svg / icon-*.png | 应用图标（含 maskable） |
| LICENSE | MIT 开源协议 |
| README.md | 项目说明 |

## 📖 新手词典（GitHub 黑话速查）

逛 GitHub 总被英文术语拦住？先记这 12 个，剩下的在应用「我的 → 新手词典」里随时搜：

| 英文术语 | 大白话 |
|---|---|
| Repository | 仓库：一个项目文件的家 |
| README | 项目说明书：仓库首页的说明文档 |
| Star | 点赞/收藏：相当于给项目点星标 |
| Fork | 复制一份：把别人的项目整个复制到自己账号下 |
| Pull Request（PR）| 提交代码申请合并 |
| Issue | 问题留言板：提问题、报 bug 的地方 |
| Merge | 合并：把改动并入主版本 |
| Clone | 克隆/下载：把项目下载到自己电脑 |
| Push / Pull | 上传 / 拉取更新 |
| Release | 发布版：一般有现成安装包可下载 |
| License | 开源协议：规定代码怎么用 |
| Open Source | 开源：代码公开免费，谁都能看能改 |
